# App Store / Play Store readiness

This is a planning checklist, not a statement of current store-policy compliance. Official policy review is deferred until an actual product and submission are authorized. Policy review date: not yet reviewed. Approval status: NOT_STARTED. Track each product and each store independently.

Allowed workflow statuses: NOT_STARTED, REQUIRED, IN_DESIGN, IMPLEMENTED, TESTED, STORE_READY, SUBMITTED, APPROVED.

| Item | Status | Evidence required |
|---|---|---|
| Developer organization setup | NOT_STARTED | Verified organization account |
| Company identity consistency | REQUIRED | Legal entity and contact approval |
| Privacy policy | REQUIRED | Reviewed product policy |
| Support URL | IMPLEMENTED | Route shell; real support workflow still required |
| Account deletion | REQUIRED | Product-specific process and verified endpoint, if applicable |
| Data disclosures | REQUIRED | Approved data inventory per store |
| Screenshots | NOT_STARTED | Approved device captures |
| Icons | NOT_STARTED | Exact master assets and store exports |
| Age rating | NOT_STARTED | Product-specific questionnaire |
| Reviewer access | NOT_STARTED | Authorized review instructions |
| App Store metadata | NOT_STARTED | Approved copy and URLs |
| Play Store metadata | NOT_STARTED | Approved copy and URLs |
| Web support | REQUIRED | Verified permanent web channel |
| Policy review date | NOT_STARTED | Dated review against official store policies |
| Approval status | NOT_STARTED | Store decision evidence |

Route existence alone does not mean STORE_READY. No store APIs or submission infrastructure is implemented.
